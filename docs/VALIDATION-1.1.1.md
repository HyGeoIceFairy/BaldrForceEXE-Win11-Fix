# 1.1.1 验证记录

## 修复目标

窗口化或无边框游戏失去前台焦点后，应立即忽略并清空键盘、鼠标移动和鼠标按钮状态；
重新聚焦后，必须重新按键或点击才会生效。

## 环境

- 系统：Windows 11 x64。
- 目标游戏：`BaldrForce.exe`，SHA-256
  `7A9341D40E24C4728ECC8666FE77BBE01EE78D65C65E7F6F9A486BA9630CAD76`。
- 显示模式：窗口化，1024×768，保持 4:3 比例。
- 兼容层：dgVoodoo2 2.87.4 x86 DirectDraw。

## 已完成验证

## 实现边界

- 输入过滤仅应用于窗口化和无边框模式；传统独占全屏继续使用游戏原有行为。
- 前台窗口判断直接使用目标 32 位进程中的 `GetForegroundWindow`，并与游戏保存的 HWND 比较。
- 安装补丁前验证受支持版本的机器码签名；失败时终止尚未恢复的游戏进程，不留下部分补丁。
- 本版本不修改磁盘上的 `BaldrForce.exe`、游戏资源或存档。

## 发布结论

本版本针对失焦输入的精确症状已完成自动复现、回归测试、正式构建和真实游戏人工验收。
沿用 1.1.0 尚未覆盖全部多显示器、DPI、驱动和传统独占全屏组合的披露，因此 v1.1.1
继续作为 GitHub 预发布版发布。
